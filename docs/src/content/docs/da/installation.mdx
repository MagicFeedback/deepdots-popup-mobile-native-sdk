# Installation

Offentlige integrationsspor i repoet:

- Android: `com.deepdots.sdk:shared-android`
- iOS: `DeepdotsSDK` med Swift-produktet `ComposeApp`

## Android

```kotlin
dependencies {
    implementation("com.deepdots.sdk:shared-android:0.2.0")
}
```

## iOS

- SPM package-navn: `DeepdotsSDK`
- Swift-produkt: `ComposeApp`
- Minimum iOS i repoet: `13`
