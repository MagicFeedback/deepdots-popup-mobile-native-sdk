# Quickstart

Demoapps bruger **Server Mode**.

## Grundtrin

1. Initialiser `DeepdotsPopups`
2. Angiv `publicKey`
3. Sæt `provideLang`
4. Aktiver `autoLaunch`
5. Kald `setPath(...)`
6. Tilfoej platformskontekst via `attachContext(...)`
