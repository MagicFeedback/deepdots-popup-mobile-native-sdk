# Quickstart

Las demos del repositorio arrancan en **Server Mode**.

## Pasos base

1. Inicializa `DeepdotsPopups` con `Mode.Server`
2. Pasa `popupOptions.publicKey`
3. Define `provideLang`
4. Activa `autoLaunch`
5. Llama a `setPath(...)`
6. Adjunta el contexto de plataforma con `attachContext(...)`

## Android

```kotlin
val options = InitOptions(
    debug = true,                              // solo logs del SDK — NO cambia el backend
    environment = Environment.Development,     // omite (o usa Environment.Production) para apuntar a prod
    mode = Mode.Server,
    popupOptions = PopupOptions(publicKey = "<your-public-key>"),
    autoLaunch = true,
    provideLang = { "en" },
    metadata = mapOf("userId" to "demo-user")
)
```

`environment` controla la URL base del backend (`Environment.Production` →
`https://api.deepdots.com`, `Environment.Development` → `https://api-dev.deepdots.com`).
Por defecto es `Production`. `debug` controla solo los logs del SDK y es independiente
del entorno: puedes tener logs activados en producción.

## iOS

```swift
let options = InitOptions(
    debug: true,                               // solo logs del SDK — NO cambia el backend
    environment: Environment.development,      // omite (o usa .production) para apuntar a prod
    mode: Mode.server,
    popupOptions: PopupOptions(id: nil, publicKey: "<your-public-key>", popups: nil, companyId: nil),
    provideLang: { Locale.current.language.languageCode?.identifier ?? "en" },
    autoLaunch: true,
    metadata: ["userId": "demo-user"]
)
```
